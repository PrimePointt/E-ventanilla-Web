# E-Ventanilla · administración web

Prototipo institucional para el Departamento de Gestión Empresarial y Ventanillas Integrales de la Comisión Estatal de Simplificación Administrativa.

La aplicación está en [`apps/web`](apps/web/README.md). Consulta allí instalación, comandos y alcance. Los documentos de contexto recibidos se conservan en `info/`; el logotipo original entregado se conserva en la raíz.

**Alcance:** una dependencia, sedes VUGE/VIM de Chiapas, costos centrales por trámite, responsables y reportes consultables. Los módulos administrativos utilizan datos simulados identificados en pantalla. Las llamadas reales se limitan a los endpoints existentes de la API y se realizan mediante un backend intermediario.
